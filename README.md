# 🚀 Notes Keeper App

A modern and user-friendly **Notes Application** built using **Kotlin + Firebase**.
This app helps users efficiently manage their notes with real-time cloud synchronization and a clean UI.

---

## ✨ Features

* 📝 Create, Edit, Delete Notes
* 🔐 Secure Authentication (Login / Signup)
* ☁️ Cloud Sync using Firebase Firestore
* 🔍 Search Notes Quickly
* 📌 Pin Important Notes
* 🌙 Dark Mode Support
* 📁 Organize Notes with Categories
* 🔄 Real-time Data Sync
